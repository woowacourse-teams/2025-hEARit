# ADR — 아키텍처 결정 기록

> ADR = 결정 시점 스냅샷("무엇을 결정했고 무엇을 기각했나"). 파일은 `docs/adr/<번호>-<slug>.md`. **추가만**, 수정/삭제하지 않는다.

## 규칙

- **소급 기록 금지** — 지나간 결정은 backfill 하지 않는다. **앞으로의 새 결정부터** 기록한다.
- 한 ADR = 한 결정. 대안과 기각 이유를 함께 적는다.
- 번호는 순차 증가(`0001-`, `0002-`, ...). 한번 부여한 번호·내용은 바꾸지 않는다(결정이 뒤집히면 새 ADR 로 supersede).

## 구조

1. 제목 / 상태(proposed·accepted·superseded) / 날짜
2. 맥락 — 어떤 문제·제약에서 결정했나
3. 결정 — 무엇으로 정했나
4. 대안 — 검토했으나 기각한 선택지와 이유
5. 결과 — 이 결정으로 생기는 영향(좋은 점·감수할 점)
